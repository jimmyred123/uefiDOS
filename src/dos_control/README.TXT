                 uefiDOS INDUSTRIAL APPLIANCE
===================================================================
 Control Volume: B:\       Target Hardware Disks: RAW PASSTHROUGH

 Available Maintenance Commands:
   EDIT     - Reboot into Hardware Bridge & Drive Router Dashboard
   ROUTER   - Display active partition and hardware routing table
   DRIVES   - Alias for ROUTER (show drive letter mappings)
   REBOOT   - Restart the PC (hardware warm reboot)
===================================================================
 HARDWARE ROUTING & PARTITION MAPPING:
 You can map physical partitions or disk images directly to DOS:
 1. Type EDIT or press [E] at the boot countdown to enter Edit Mode.
 2. Press [C], [D], or [E] to map a physical partition, standalone
    .VHD/.IMG disk image, or 64 MB RAM scratch disk, or press [N]
    inside drive setup to create a new blank .VHD.
 3. Choose Read/Write, Read-Only, or RAM Overlay mode.
===================================================================
 To manage drives, live media, or utilities: type EDIT or press [E]
